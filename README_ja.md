# Keybind Guard — Minecraft 1.21.1 / NeoForge

**現状：試作ソースコード。完成済みの動作確認済みJARではありません。**

Minecraftの起動途中で `options.txt` が保存され、まだ登録されていないMODのキー設定が消えてしまう現象を軽減するための、クライアント専用MODです。

## 対応環境

- Minecraft **1.21.1**
- NeoForge **21.1.230以上、21.1系列**（開発ターゲット：21.1.259）
- Java **21**
- クライアントのみ。XServerなどのサーバーへの導入は不要です。

## 修正の仕組み

1. Minecraftが設定を読む／保存する前に、`options.txt` の `key_` で始まる設定行を記憶します。
2. 保存処理で消えたキー設定行だけをファイルに戻します。既存の新しい値は上書きしません。
3. MOD登録後の最初のゲーム処理でキー設定を読み込み直します。

**既に消えたキー設定は復元できません。** 導入後に一度設定し直してから、次回起動でも残るか確認してください。

## ソースからJARを作る

### 方法A：GitHub Actions（ローカルのGradle不要）

1. このフォルダーの全ファイルをGitHubリポジトリにアップロードする（`.github` フォルダーも含める）。
2. リポジトリの **Actions** → **Build and test mod** → **Run workflow** を押す。
3. 成功した実行結果の **Artifacts** からビルド成果物を保存する。
4. ZIP内の `keybindguard-1.21.1-0.1.0-beta.1.jar` をテスト用に取り出す。

**注意**：GitHub Actionsが成功しても、Minecraftでの動作保証はありません。

### 方法B：Windows PCでビルド

JDK 21・Gradle 8.8を導入し、ソースのルートで以下を実行します。

```powershell
gradle --no-daemon clean build
```

生成先は `build\libs\` です。Gradle本体はこのZIPに含まれていません。

## 動作確認

1. Minecraftを終了し、プロファイルの `options.txt` をバックアップする。
2. ビルド済みのJARをクライアントの `mods` に入れる。
3. 原因切り分け中はDefault Optionsなど、他のキー復元MODを一時的に無効にする。
4. Minecraftを起動し、MODのキー割り当てを変更する。
5. 正常終了したら再起動して、設定が残っているか確認する。
6. 起動できない場合はJARを外し、ログを確認する。
